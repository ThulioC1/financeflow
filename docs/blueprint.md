# **App Name**: FinanceFlow

## Core Features:

- Google Authentication: Secure user authentication using Google Sign-In.
- Income Tracking: Record and manage income entries, categorizing by type (quinzena 1, quinzena 2, extra) and tracking payment status.
- Expense Tracking: Log expenses with descriptions, categories, and recurrence options. Manage payment status and automate recurring expense entries.
- Dashboard Overview: Display a summary of the current month's financial status, including initial balance, total income, total expenses, and current balance, using visual cards and graphs.
- Monthly History: Review past months' financial data, showing total income, total expenses, and final balance. Automatically carry over the final balance to the next month as the initial balance.
- Data Protection: Restrict users' ability to access the database through filtering based on userID.
- Balance Forecasting: Employ an AI tool for simple financial forecast on future income based on past income data

## Style Guidelines:

- Primary color: Soft, muted blue (#64B5F6) to evoke trust and reliability.
- Background color: Light gray (#F5F5F5) for a clean, uncluttered look.
- Accent color: Green (#A5D6A7) to highlight income and positive financial status.
- Headline font: 'Poppins' sans-serif, classification: geometric sans-serif for a modern, fashionable appearance. Body Font: 'PT Sans' sans-serif, classification: humanist sans-serif to allow long spans of text.
- Use minimalist icons to represent income, expenses, and different categories.
- Responsive, mobile-first design with a clear tab-based navigation: Dashboard, Income, Expenses, History.
- Subtle transitions and loading animations to enhance user experience.
